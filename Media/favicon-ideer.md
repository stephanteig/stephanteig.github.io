20 konsepter til favicon + veiledning for å sjekke meta description og Open Graph-tags.

## 20 Favicon-konsepter

### 1. ST-monogram — Instrument Serif italic
**Beskrivelse:** Bokstavene "S" og "T" satt i Instrument Serif italic, smeltet lett sammen. Lys tekst på mørk bakgrunn (`#0b0b0f`).  
**Tone:** Elegant, kreativ, personlig.

**Tone:** Teknisk, ren, kode-estetikk.

---

### 3. Filmkamera — violet gradient
**Beskrivelse:** Minimalistisk kamera-silhuett (side-profil) fylt med gradient fra violet `#7c5cfc` til pink `#d44fa8`. Svart bakgrunn.  
**Tone:** Profesjonell, filmbransjen, moderne.

---

### 4. Kamera-aperture (iris)
**Beskrivelse:** Seks eller åtte iris-blad i stilisert aperture-form. Hvite blad på svart, med én violet detalj i sentrum.  
**Tone:** Fotografisk, minimalistisk, gjenkjennelig.

### 5. Klapperboard — minimalistisk

### 6. Filmrull

## Verktøy og prosess

**Anbefalt størrelse:**
- `32×32 px` — standard nettleserfavicon
- `180×180 px` — apple-touch-icon (iOS hjemskjerm)
- Eksporter begge størrelsene fra samme kilde-fil

**Anbefalte verktøy:**
- **Figma** — lag i vektorer, eksporter til PNG
- **Illustrator / Affinity Designer** — for SVG-baserte ikoner
- **Canva** — enkelt og raskt for monogram-konsepter
- **favicon.io** — generator for tekst-baserte favicons, konverterer PNG → ICO

**Filformat:**
- Lagre som `Media/favicon.png` (erstatter eksisterende)
- Lag også `favicon.ico` i rot-mappen for bredest mulig nettleserstøtte
- SVG-favicon støttes i moderne nettlesere: `<link rel="icon" type="image/svg+xml" href="favicon.svg">`

## Sjekk meta description og Open Graph-tags

### 1. Nettleser DevTools (raskest)
1. Åpne `https://stephanteig.github.io` i Chrome eller Firefox
2. Høyreklikk → **Inspect** (eller `F12`)
3. Gå til fanen **Elements**
4. Trykk `Ctrl+F` (Win) / `Cmd+F` (Mac) for å søke i DOM
5. Søk etter `meta name="description"` — du ser `content`-attributtet
6. Søk etter `og:` — finner alle Open Graph-tags (`og:title`, `og:description`, `og:image`, osv.)

---

### 2. Facebook Sharing Debugger (mest pålitelig for sosiale medier)
- Åpne: **https://developers.facebook.com/tools/debug/**
- Lim inn `https://stephanteig.github.io`
- Klikk **Debug**
- Du ser nøyaktig hva Facebook og LinkedIn vil vise ved deling
- Klikk **"Scrape Again"** etter å ha gjort endringer for å tvinge cache-refresh

---

### 3. OpenGraph.xyz (raskest visuell forhåndsvisning)
- Åpne: **https://www.opengraph.xyz/**
- Lim inn URL → forhåndsvisning for Twitter, Facebook, LinkedIn, Slack
- Ingen innlogging nødvendig

---

### 4. Terminal — curl-sjekk
```bash
curl -s https://stephanteig.github.io | grep -E 'meta name="description"|og:title|og:description|og:image'
```
Viser alle relevante meta-tags direkte i terminalen.

---

### 5. Twitter/X Card Validator
- Åpne: **https://cards-dev.twitter.com/validator**
- Lim inn URL og klikk **Preview card**
- Viser hvordan lenken ser ut når den deles på X/Twitter

---

### Hva du ser etter

| Tag | Hva den gjør |
|---|---|
| `<meta name="description">` | Teksten under tittelen i Google-søk |
| `<meta property="og:title">` | Tittelen som vises ved deling på sosiale medier |
| `<meta property="og:description">` | Beskrivelse ved deling |
| `<meta property="og:image">` | Thumbnail-bilde ved deling (bør være min. 1200×630 px) |
| `<meta property="og:url">` | Kanonisk URL |
| `<meta name="twitter:card">` | Korttype for Twitter (vanligvis `summary_large_image`) |
